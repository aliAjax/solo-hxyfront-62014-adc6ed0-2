# 赛鸽训放赛务工作台

面向赛鸽棚的训放/比赛事务前端：单条录入与批量粘贴导入、组合筛选、系统校验、冲突阻断排名、
并列/弃权/复放/迟到补录处理、未归巢分级提醒、单羽档案与血缘冲突检测；数据 localStorage 持久化，
最近一次批量操作可撤销，导出仅包含当前筛选结果。

## 本地运行

```bash
npm install
npm run dev        # http://localhost:62014
```

## 其他命令

```bash
npm run typecheck  # tsc 严格类型检查
npm test           # 领域逻辑单测（esbuild 打包到 node 运行，59 项）
npm run build      # 生产构建
```

## 功能与页面

| 模块 | 说明 |
| --- | --- |
| 鸽棚总览 | 在册鸽数、参赛羽次、归巢率、平均分速、异常计数；近期场次、跨场未归巢提醒、血统分布 |
| 训放记录 | 足环/血统/距离段/天气/健康/归巢状态/场次组合筛选；单条录入、批量粘贴导入、撤销、导出当前筛选 CSV |
| 训放成绩排行 | 按场次排名；异常未清零时**阻断排名**并逐条列明、一键跳转修正；并列同名次跳号（1224）、弃权、复放参考区、封榜后迟到补录区、未归巢五级提醒 |
| 单羽档案 | 历次成绩（含名次/复放/补录/封榜未归标记）、参赛/归巢率/冠军/均分速统计、向上 3 代血缘树、配偶与子代 |
| 配对血缘 | 登记“父 × 母 → 子代”；检测重复父母登记、性别颠倒、亲子年份倒置、直系回血、三代内近交 |

## 关键规则

- **校验**：放飞/归巢时间（必填、先后顺序、不得晚于当前时间、未来开笼提醒）、空距（正数、与场次
  偏差）、速度（200–1700 m/min 合理区间、手填与空距/耗时推算偏差 >2% 提醒、手填优先）、同场次同足环
  查重、状态/天气/健康词库归一（如 迷失→未归巢、侧风→逆风、受伤→伤）。
- **阻断**：任一条记录存在 error 级问题时，该场次不出名次，修正后立即恢复；warning 不阻断，集中展示。
- **排名**：仅“归巢”参与；手填速度优先，否则 `空距 ÷ (归巢−放飞)`；分速差 ≤ 0.5 m/min 判并列。
  复放鸽按速度列入参考名单但不计正式名次；封榜后的归巢记录进入补录区。
- **未归巢超时分级**：按距离段给时限（短 8h / 中 18h / 长 36h / 超长 48h，恶劣天气 ×1.5），
  分为 开笼待归（蓝）→ 临近超时（黄，过半）→ 超时未归（橙）→ 严重超时（红，1.5 倍时限）→ 封榜未归。
- **批量导入**：支持 Excel 直接粘贴（制表符/逗号）、表头自动识别或固定列序、中英文多种时间写法；
  场次名自动匹配已有场次或建新场次；预览逐行给出校验结果；撤销只精确移除本批新增数据。
- **持久化**：所有数据保存在浏览器 localStorage（`pigeon-loft-workbench:v1`）；顶部“演示数据”可一键
  恢复内置示例（示例当前时间固定为 2026-09-13 18:00，便于演示各超时级别）。

## 技术栈

React 19 + Vite 7 + TypeScript（strict）。无后端、无第三方运行时依赖；核心领域逻辑集中在
`src/lib/domain.ts`，配有 `scripts/domain.test.ts` 单测。
